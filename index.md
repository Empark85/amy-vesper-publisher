# Amy Vesper Publisher

Amy Vesper Publisher is a private, single-user tool used only by the owner of the [Amy Vesper YouTube channel](https://www.youtube.com/@amyvesper) to upload and manage videos on that channel through the YouTube Data API. It is not offered to the public and has no other users.

## Privacy Policy

*Last updated: November 19, 2026*

**Data accessed.** The tool uses Google OAuth to access only the owner's own YouTube channel (uploading videos, thumbnails, captions, playlists, localized titles and descriptions, and posting comments).

**Data storage.** OAuth tokens are stored only on the owner's personal computer. No data is sent to any server other than Google's own APIs.

**Data sharing.** No data is sold, shared with or transferred to any third party. No data from other users is collected.

**Revoking access.** Access can be revoked at any time at [myaccount.google.com/permissions](https://myaccount.google.com/permissions).

The tool's use of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements, and to the [YouTube Terms of Service](https://www.youtube.com/t/terms).
